⭐「用途 + 要找什麼 + 要注意什麼」
⭐「市場意義」
⭐「價量該怎麼看」
⭐「可以直接放進你的策略的重點」

整理成你未來寫任何 data_process 都能用的 核心章節。

🟥 ① 均價 long_% < 0 + MACD_% > 0
➜ 位置便宜 + 動能翻多 → 尋找『上漲潛力』
🧭 用途

找 轉強初期的潛力股

找 剛要起漲、布局點 的股票

找 便宜位置 + MACD 翻多 → 多頭啟動的早期訊號

🔍 要找的是什麼？
✔ 找「量開始變大」的股票（強力訊號）

量能突然變大 → 主力開始啟動

這種最容易 2–3 日內出現攻擊 K

✔ 找「價站上五日線」的股票（確認訊號）

價站上 5MA → 確認開始上攻

低檔 MACD 翻多 + 站上 5MA = 轉強

✔ 找「均價 long_% 接近轉正」的股票（續航訊號）

long_% 數字越接近 0 → 越脫離便宜區 → 越接近發動點

⚠️ 要注意什麼？
❌ MACD 翻多但量完全沒有 → 偽轉強

常常是短線反彈，不是主力行情

有量才有攻擊，量弱只能維持弱多頭

❌ MACD 翻多 + 均價偏低，但收黑 / 上影長

有人「拉高出貨」

要避免追高

❌ MACD 翻多但均價 long_% 越變越負

代表價格還在破底 → 動能假訊號

⭐ 結論：這組條件找的是「上漲潛力」

→ 重點是 量要放大、價要站上 5MA
→ 才算真正會噴的股票

🟦 ② 均價 long_% > 0 + MACD_% < 0
➜ 位置偏貴 + 動能轉空 → 尋找『風險訊號』／減碼點
🧭 用途

判斷是否進入 高檔轉弱

判斷是否進入 出貨階段

判斷是否為 短線拉回 or 開始走空

🔍 要找的是什麼？
✔ 找「量放大 + 跌」＝高風險（出貨）

高檔 MACD 翻空

均價偏高

又爆量下跌
→ 最危險（主力確實在倒貨）

✔ 找「量縮的 MACD 翻空」＝健康拉回

高檔 MACD 翻空

量縮
→ 正常修正
→ 未必是跌勢，可等止穩再上

✔ 找「回測 5MA、尚未跌破」＝假轉弱機會高

很多強勢股會 MACD 假翻空

回 5MA 又拉回 → 轉強信號

⚠️ 要注意什麼？
❌ 量增 + 黑 K + MACD 翻空 → 逃命訊號

主力倒貨 → 要躲

❌ 均價 long_% > 0 持續走高

越代表價格偏高 → 下跌空間變大

❌ MACD_% 越來越負、柱體變大

代表跌勢加速

⭐ 結論：這組條件找的是『風險』而不是『潛力』

→ 重點是 量是否放大（放量 = 出貨、量縮 = 修正）
→ 價格是否守住 5MA（守住可能再上、不守就走弱）

📘 總整理：兩組條件的核心差異
條件組合	市場意義	要找什麼	要注意什麼	重點
均價 < 0 + MACD > 0	低檔轉強 / 潛力股	放量、站 5MA	量弱假轉強、上影線	是否有「量帶價」啟動上漲
均價 > 0 + MACD < 0	高檔轉弱 / 風險區	放量出貨、跌破均線	放量黑 K、MACD 柱體放大	是否進入出貨 or 健康拉回
🏆 一句話總結：
🔺 均價 < 0 + MACD > 0 = 在找「會漲的」

👉 低檔轉強 → 要看「量能是否啟動」。

🔻 均價 > 0 + MACD < 0 = 在找「要跌的」

👉 高檔轉弱 → 要看「量能是否出貨」。
